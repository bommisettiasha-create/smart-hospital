# 🏥 Smart Hospital - Patient Management System
### Made by Asha Bommisetty ❤️

A complete Hospital Management System built with Spring Boot and modern UI.

🔗 **Live Demo:** http://localhost:8081
🔗 **GitHub:** https://github.com/bommisettiasha-create/smart-hospital

### ✨ Features
- ➕ Add New Patient (Name, Age, Disease)
- 🔍 Live Search by Patient Name
- ❌ Delete Patient
- 📊 Clean Blue UI - Responsive Design
- 💾 H2 In-Memory Database

### 🛠️ Tech Stack
- **Backend:** Java 17, Spring Boot 3, Spring Data JPA
- **Frontend:** HTML, CSS, JavaScript (Fetch API)
- **Database:** H2 Database
- **Build Tool:** Maven
